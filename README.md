# מרוץ לצדק

משחק כיתתי של טכנודע חדרה המבוסס על מפגש האסטרונומיה ״היכן הצדק?״.

1. פותחים את המשחק ובוחרים בהגדרות 2–6 קבוצות, שמות ואורך מסלול.
2. מקריאים את השאלה ובוחרים ״פתיחת זמזמים״. כל קבוצה לוחצת על המקש שלה (1–6) במקלדת משותפת או על הכפתור שלה. עם משרוקיות פיזיות המורה לוחץ על הכפתור של הקבוצה ששמע ראשונה.
3. הקבוצה שנבחרה עונה בקול. המורה מאשר תשובה נכונה או מעביר את התור לקבוצות שעדיין לא ניסו.
4. תשובה נכונה מקדמת בשני צעדים. בשאלת אתגר היא מקדמת בארבעה צעדים. הקבוצה הראשונה שזמזמה מקבלת עוד צעד אם ענתה נכון.
5. ״מסך הקרנה״ פותח חלון תצוגה נוסף באותו דפדפן. אפשר לגרור אותו למסך המקרן. השאלה, המסלול וחשיפת התשובה מסונכרנים עם חלון המורה.

המשחק עובד בדפדפן ושומר את מצב המרוץ באחסון המקומי. הוא אינו אוסף פרטי תלמידים. לפריסה מקומית פותחים את התיקייה בשרת HTTP סטטי ומבקרים ב-`index.html`.

## מרוץ אישי בטלפונים

המורה בוחר ״משחק בטלפונים״ ומקרין את קוד ה־QR או משתף את קישור ההצטרפות. כל תלמיד נכנס עם שם קטן או כינוי ומקבל חללית אישית. המורה פותח את השאלה הראשונה ומעביר את הכיתה לשאלות הבאות. בכל שאלה יש 18 שניות לענות פעם אחת מהטלפון. תשובה נכונה מקדמת את החללית, והתשובה הנכונה הראשונה מקבלת צעד נוסף. מסך ההקרנה מציג את שש החלליות המובילות ואת הדירוג של כל המשתתפים.
