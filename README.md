# מרוץ לצדק

משחק כיתתי של טכנודע חדרה המבוסס על מפגש האסטרונומיה ״היכן הצדק?״.

## מרוץ אישי בטלפונים

המורה בוחר ״הזמנת תלמידים״ ומקרין את קוד ה־QR או משתף את קישור ההצטרפות. כל תלמיד נכנס עם שם קטן או כינוי ומקבל חללית אישית. חדר ההמתנה מציג את המצטרפים. כפתור ״התחלת המרוץ״ חושף את השאלה הראשונה, והמורה מעביר את הכיתה משם בין כל 20 השאלות. בכל שאלה יש 18 שניות לענות פעם אחת מהטלפון. תשובה נכונה מקדמת את החללית, והתשובה הנכונה הראשונה מקבלת צעד נוסף. מסך ההקרנה מציג את כל החלליות על מפת החלל ואת הדירוג של המשתתפים. המרוץ נמשך עד לסיום השאלה האחרונה, גם אם חלליות כבר הגיעו לצדק.
